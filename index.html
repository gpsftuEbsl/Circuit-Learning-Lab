負載隔離與扇出優化實驗室

透過三個關卡，用真實 RC 充電模型體會為什麼工程師要在訊號路徑上插入 Buffer——從波形變形、雜訊隔離，到時脈樹的 skew 平衡。

關卡一 · 扇出增加，訊號為何變慢？

拖動 Fanout 滑桿，觀察主線要「充電」的寄生電容總量如何隨負載數量增加，導致波形爬升變慢、延遲超出時序預算。當你觸發 TIMING VIOLATION 時，試著插入 Buffer 分攤負載。

關卡二 · 一個吵鬧的負載，會拖累整條主線嗎？

Load C 是個高速切換的匯流排（雜訊源），它的切換雜訊可能經由共用主線「倒灌」回去，干擾原本乖乖牌的 Load A。試試在沒有 Buffer 隔離、以及裝上專屬 Buffer 之後，分別觸發雜訊看看差別。

關卡三 · 哪一種拓撲讓訊號同時抵達？

時脈樹最怕的不是「慢」，而是「不一致」——Skew（到達時間差）太大會讓正反器誤判。選一種拓撲，看看每個末端負載的到達時間分佈。
